# Author Style Profile

This bundled file is an immutable template. With explicit authorization, copy
it to a location resolved by the STAR Writing state-and-path policy.
`.star-writing/author-style-profile.md` is the project-local override; an
explicit path, `STAR_WRITING_PROFILE`, or the platform user-configuration
directory may hold the cross-project profile. Infer a preference from repeated
evidence or confirm it with the author; do not turn one local edit into a
permanent rule.

This profile governs presentation, not scientific truth. A current paper
contract, verified evidence, and explicit task instruction override it whenever
they conflict.
