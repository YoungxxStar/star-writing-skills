## Naming rules

- Prefer established field terminology when it describes the same object and
  information contract.
- Verify technical usage through standards, authoritative definitions,
  canonical literature, or primary sources appropriate to the field.
- For a new, ambiguous, or cross-field term, use an applicable, sufficiently
  mature Wikipedia page as an optional cross-check for aliases, common usage,
  disambiguation, and source trails. Follow the responsible references for
  consequential technical claims; do not treat Wikipedia alone as proof of a
  scientific proposition.
- Introduce a new term only when an established term would collapse a material
  distinction. State that distinction operationally.
- Keep one preferred term for one referent. Preserve deliberate distinctions
  among related objects instead of normalizing them by surface similarity.
- Define every retained acronym and symbol before use. Use one symbol for one
  object within the declared scope.
