# Candidate Records

This directory contains one explicitly authorized, public-safe Markdown record
per reusable evolution candidate. Use the schema and lifecycle in
[../candidate-template.md](../candidate-template.md) and
[../README.md](../README.md).

Name records `EVO-YYYYMMDDTHHMMSSZ-short-slug.md`. Keep filenames stable across
status changes. Do not place task notes, manuscript text, project facts, raw
dialogue, secrets, or machine-specific paths here. The directory may contain no
candidate records; absence of a record is not evidence that a workflow was
never considered.
